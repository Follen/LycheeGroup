# 荔枝组队 · Lychee LFG

简体中文 · [English](README.en.md)

魔兽世界正式服组队插件。在一个窗口里寻找队伍、管理招募，并记录与玩家的组队经历。

当前版本为 **1.2.5**，目标客户端为正式服 **12.1.5**（Interface `120105`），支持中文和英文。版本变更见[更新日志](CHANGELOG.md)。

## 功能

- **寻找队伍**：浏览地下城、团本、地下堡和 PvP 等活动，搜索、筛选队伍，赛季地下城可排除已有相同职业、专精或同职业同职责成员的队伍，并按嗜血来源筛选；钥石菜单显示自己的赛季限时层数与单本分，在列表查看创建备注，查看成员信息与申请状态。本次会话拒绝过自己的队伍排在最后，并显示距拒绝过去的时间。
- **创建组队**：发布和修改招募信息，查看申请者的大秘境记录、当前副本单本分和已知阵营，点击阵营可切换种族名称，邀请成员。点击活动旁星标主动收藏当前创建条件，应用时保留当前标题和说明，由玩家确认发布；不自动保存创建历史。小队活动直接显示当前成员，团队活动悬停职责人数查看分组名单和已知装等，团长与助理可在相关成员均未战斗时拖动换小队；当前赛季团本提供职业增益缺口提示。
- **新申请声音（未发布）**：新申请立即提醒，正在看列表也提醒；播放后 3 秒内的新申请只更新列表，不排队或补播，3 秒后下一批新申请才再次提醒。默认原生提示音，可在“设置 → 常规”切换荔枝内置语音或关闭，并试听；接管原生新申请循环声音。
- **角色偏好**：自动申请开关、申请职责、各分类筛选和排序按角色保存，重载后恢复；申请弹窗与主界面的自动申请开关同步。
- **表格操作**：悬停表头后拖动分隔线调整列宽，右键分隔线恢复该表默认列宽，点击数字或时间表头切换升降序；列宽与方向按角色保存。
- **筛选与成员图标**：窗口内筛选面板支持评分、装等和人数范围；赛季地下城的职责组合与同职业／同专精过滤默认在弹窗中直接点选，也可在“寻求组队”开启“主界面重要筛选”，移至“我的申请”区域。寻队成员头像可选圆形／原版圆角方形、职业色边框、缩放与实际队长皇冠。
- **队伍屏蔽**：右键屏蔽同标题队伍并记住命中队长，刷新或重载后继续生效；在设置“屏蔽名单”中逐项移除或清空，与玩家笔记独立。
- **玩家详情**：可复制 WCL 与 Raider.IO 角色链接。
- **玩家笔记**：账号内各角色共享推荐、中性或拉黑记录，再次组队时提醒；支持导入与导出。
- **大秘境历史**：按角色保存副本、层数、时间和队友，方便回顾与补充笔记。
- **界面设置**：选择“默认主题”“透明毛玻璃”或第三方主题，重载后生效。修改主窗口快捷键、整体缩放和字体大小，悬浮窗使用独立的缩放设置；再次点击设置按钮返回来源页。自动适配 RurutiaSuite 顶栏入口，需同时开启“显示悬浮窗”和“悬浮窗兼容”。Ellesmere DataBars 可添加 `荔枝组队` 插件块，显示荔枝图标、名称及申请状态。

界面采用原生 Lua，内置 [LycheeUI V1.0.0](https://github.com/Follen/LycheeUI/tree/v1.0.0)，业务模块按需加载。安装时无需另外安装 UI 库。

功能实现与验证范围见[产品文档](Product.md)。

## 安装

1. 下载或克隆本仓库。
2. 将 [`addon/`](addon) 下的四个文件夹复制到游戏目录 `World of Warcraft/_retail_/Interface/AddOns/`：

   ```text
   LycheeGroup
   LycheeGroup_Group
   LycheeGroup_Notes
   LycheeGroup_UI
   ```

3. 启动或重启游戏，在插件列表中启用荔枝组队，输入 `/lg` 打开。

## 常用命令

| 命令 | 操作 |
| --- | --- |
| `/lg` | 打开或关闭主窗口 |
| `/lg create` | 创建与管理组队 |
| `/lg notes` | 打开玩家笔记 |
| `/lg settings` | 打开设置 |
| `/lg floattest` | 临时在屏幕中央显示独立悬浮窗，再次执行恢复；用于检查当前真实浮窗 |
| `/lg note` | 记录当前目标玩家 |
| `/lg note 玩家名-服务器 理由` | 按姓名记录玩家 |

`/lycheegroup` 与 `/lg` 等效。

游戏原生组队绿眼睛：已有预组队招募时，左键打开荔枝创建页；有预组队申请时打开寻队页并定位，同时排本也如此。只有排本时左键保留游戏原有队列菜单，右键也保持原生行为。

按住主窗右下角斜线拖动柄：横拖调整宽度，竖拖调整高度，斜拖同时调整宽高。窗口有最小尺寸限制，字体放大时下限随之提高；各页重新布局，当前输入和选择保留。松手保存当前角色的尺寸，关闭、重开和重载后继续使用。拖动尺寸与整体缩放、字体大小分别控制。

主窗默认快捷键为英文半角分号 `;`，只在尚无本插件绑定且该键未占用时初始化。可在设置“常规”修改快捷键，并选择跟随游戏、简体中文或 English（重载后生效）。在“界面显示”选择字体，将字体大小调整为 70%–130%，或将主窗整体缩放调整为 75%–125%（均以 100% 为基准，立即生效）。默认内置“荔枝字体 / LycheeFont”，中文界面整套使用雅黑，英文界面使用 Inter；也可继续使用游戏或共享字体。

## 开发

1.1.5 提供 `LycheeGroup.API.Floating`，用于接入现有顶栏或其他入口。接口支持状态订阅、挂载、刷新、归还和展开同一份悬浮列表；接入合同见[架构文档](Architecture.md#92-浮窗公开接口)。[`RurutiaSuite 适配`](addon/LycheeGroup/Adapters/Rurutia.lua)与 [`DataBroker 适配`](addon/LycheeGroup/Adapters/DataBroker.lua)独立放在 `Adapters/`，随主包分发，也作为接口使用示例。

使用 Lua 5.1 在仓库根目录运行离线测试：

```sh
lua tests/runner.lua
```

可在命令后指定模块，例如 `lua tests/runner.lua core notes`；未知模块名会明确报错并返回非零退出码。主题重载、布局、main 对照与内存测试入口见 [验证说明](tests/theme_reload.md)。

本地控件树预览：运行 `lua tests/ui_preview.lua`，再打开 [`tests/ui-preview.html`](tests/ui-preview.html)。生成的 `tests/preview-data.js` 仅保留在本地，不提交到版本库；预览使用样例数据，不代表游戏内验证。

[`tools/Build-Addon.ps1`](tools/Build-Addon.ps1) 用于打包，默认从相邻的 `LycheeUI` 源码目录同步内置库，也可用 `-LibraryPath` 指定位置。独立源库从 `https://github.com/Follen/LycheeUI.git` 克隆，并检出 `v1.0.0`；同步脚本会核对冻结清单与文件哈希。
