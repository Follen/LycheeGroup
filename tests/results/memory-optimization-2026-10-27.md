## 实现与分配对照

| 路径 | 修改与同输入结果 |
| --- | --- |
| 配置写入 | 事务只复制本次写入的容器，已经封存的迁移标记复用。预热角色单键写入由 17.078 降至 1.016 KiB/次，减少 94.1%；包选择不再复制无关目录。提交、重入通知、迁移及默认来源合同不变。 |
| 寻队筛选 | `settings.find.*` 不再触发无消费关系的 Settings.Sync。设置页已建但隐藏时，数值筛选编辑由 37.669 降至 11.075 KiB/次，减少 70.6%；50 次编辑的 Settings.Sync 从 50 次降至 0，配置读取从 1701 降至 301。 |
| 固定列布局 | 九个固定区域仅在实际列几何、偏移或行身份改变时重写，隐藏清除行版本；队长、标记及成员仍刷新。100 次稳定刷新中 SetPoint 从 19,700 降至 9,800，ClearAllPoints 从 19,100 降至 9,200，尺寸写入从 20,200 降至 12,500。 |
| 共享图标与颜色 | 每次核对实际样式记录，无记录时跳过所有权查询和观察；有记录时保留原语义。立即颜色写入不再读取并构建无用起点，10,000 次调用少分配 937.5 KiB、少读颜色 10,000 次。普通 Glyph 100,000 次反馈的离线中位耗时从 315 降至 105 ms。 |
| 笔记编解码 | JSON 片段直接交给 Base64 编码器，解码使用 384 槽字节缓冲。1000 条相同记录单次编码由 1863.147 降至 1519.849 KiB，减少 18.4%；解码由 1142.950 降至 1033.508 KiB，减少 9.6%。格式、错误返回和公开同步接口保持。 |

上述分配为 Windows Lua 5.1 中暂停回收的独立进程测量；界面路径包含替身开销。固定列优化的离线耗时范围重叠，未据此声明可靠的总 CPU 降幅。分层夹具中，100 次完整的 100 条名单更新，业务服务自身约分配 2.454 KiB，模拟原生返回对象约分配 5984.375 KiB；缓存命中的 GetResults 无新增分配。完整名单与必要事件读取继续保留，没有截断数据、删减动画或调整游戏 GC 策略。

## 游戏实测

正式服 12.1.5.70575，同一进程及角色，正常动画，字号和 UI 缩放 100%；`scriptProfile=0`，前台／后台上限 120／30，测量时约 30 FPS。峰值按五个产品包同一采样时刻合计，Guide 本轮未加载。页面与字号通过真实控件回调操作，团本和申请者组合使用私有 Preview，未执行真实申请或邀请。

默认与毛玻璃循环全程未主动 GC；列表和组合场景完成自然阶段后，另行进行诊断回收。密集列表最终打开状态回收后为 6,555,742 字节，重复阶段保留量差为 −39.609 KiB；本轮没有保留量增长。首次滚动使行池由 12 增至 13，Frame 由 569 增至 574，region 由 2485 增至 2531，因此池和对象稳定检查仍记为失败。后续组合场景的完整往返复用检查通过，不能覆盖这次冷列表的失败结果。

自然峰值受实际搜索内容及回收时点影响。本轮密集列表采样峰值高于优化前的 26,840,779 字节；相邻轮次的数据与回收过程不同，不用它们计算版本优化比例。默认及毛玻璃循环中的全客户端内存刷新观察器分别耗时 6117.978／6521.431 ms，单次范围 62.181–80.748／68.354–86.223 ms，单列为测量开销。原生对象计数不提供引擎侧字节归因。

最终编解码另用同一批 1000 条私有记录，在游戏中交替调用基线与候选各三次。481,719 字节输出及所有解码字段一致。编码基线为 111.069–115.609 ms，候选为 105.400–107.447 ms；解码基线为 107.095–113.870 ms，候选为 102.224–112.026 ms。正式安装路径的组合场景编码为 100.501–102.674 ms、解码为 101.161–104.222 ms。1000 条同步处理仍会占用约 100 ms，本轮保留公开接口的同步行为。

曾试验编码字节缓冲候选，分配更少但原生编码耗时增加，已撤回；其测量保留在归档的 `codec-comparison.json`，最终报告以 `codecFinal` 为准。切换毛玻璃的旧探针首次因 Guide 未加载而访问 nil，未改变主题；修正该探针前置检查后完成切换与恢复，该失败也保留。

## 等价与验证

完整 runner 通过 57,452 条断言，0 个失败模块；17 个布局检查脚本、6608 项架构检查通过，31 个共享库冻结文件与源库一致。15 个修改或新增 Lua 文件语法通过。默认／毛玻璃、中文／英文、100%／130% 字号共 120 个可见界面投影与基线完全一致，SHA-256 为 `a9b46cdb86652852a2ca4e140c3d28387ffd6c5531c0b9dfbce76c2322ff58e4`。1359 项固定列专项另覆盖 70% 字号、列拖动、窗口缩放、状态样式、脚注、清空后同身份重入及滚动换绑；Transfer 9156 项新旧对照覆盖完整字节、截断、非法输入、稀疏及嵌套数据，新增回归覆盖调用重入和异常后的独立缓冲。
